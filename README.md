This is a practice repository, to understand better how to use these tools, and to have a place to test them without worrying about breaking anything.

These is the main tech-stack used in this project:

- App Router
- SSG / ISR rendering strategies
- TanStack Query
- Chakra UI
- TypeScript.

Also, it uses dummy data from https://dummyjson.com/, which is a free API for testing and prototyping.
